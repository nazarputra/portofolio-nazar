# Portofolio & CV ATS — Nazar Putra Hawali, S.Kom.

Website portofolio responsif dengan dukungan **Mode Dark & Light** (tema utama Hitam, Font Kuning, List Biru) serta **CV ATS PDF** siap unduh.

## Berkas Utama (Semua di Folder Root — Anti-Gagal Upload GitHub)
- `index.html` — Halaman utama portofolio (CSS & JS sudah tertanam langsung)
- `cv-ats.html` — Halaman pratinjau & cetak CV ATS
- `profile.jpg` — Foto profil formal
- `graduation.jpg` — Foto wisuda
- `CV-ATS-Nazar-Putra-Hawali.pdf` — Dokumen CV ATS 1 halaman A4
- `vercel.json` — Konfigurasi deployment statis Vercel

## Cara Upload ke GitHub Web & Deploy ke Vercel (`*.vercel.app`)

1. Buka repository GitHub Anda (`portofolio-nazar`) &rarr; klik **Add file** &rarr; **Upload files**.
2. Klik **choose your files** lalu masuk ke folder `C:\xampp2\htdocs\portofolio`.
3. Pilih semua file utama berikut (tahan `Ctrl` lalu klik atau `Ctrl+A` pada file-file di root):
   - `index.html`
   - `cv-ats.html`
   - `profile.jpg`
   - `graduation.jpg`
   - `CV-ATS-Nazar-Putra-Hawali.pdf`
   - `vercel.json`
   - `README.md`
4. Klik **Commit changes**.
5. Vercel akan otomatis melakukan redeploy dalam ~10–20 detik di `https://portofolio-nazar.vercel.app`.
